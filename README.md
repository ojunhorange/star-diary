# 별자리 일기

일기를 쓰면 별이 하나 찍히고, 별이 모이면 나만의 별자리가 뜹니다. 그 별자리의 그리스 신화와 철학 개념으로 "지금의 나"를 읽고, 이번 주에 해볼 작은 행동 하나로 이어지는 자기이해 웹 앱입니다.

GDG On Campus Korea University **BYPP** 해커톤 출품작 (하루짜리 개인 프로젝트, AI 코딩 에이전트와 바이브코딩).

## 왜 만들었나

요즘 청년들은 외적 성취가 어려운 시대에 MBTI, 사주, 애착유형 같은 검사로 자기를 알아가려 합니다. 그런데 그 탐구는 "검사하고 끝"으로 소비됩니다. 네 글자를 받고, 며칠 뒤엔 잊어버립니다.

저도 그랬습니다. 검사 결과는 많이 모았는데, 정작 내가 요즘 어떤 사람인지는 아무 데도 기록되지 않았습니다. 그래서 검사 대신 **기록**으로, 한 번 보고 끝이 아니라 **쌓이고 행동으로 이어지는** 자기이해 도구를 만들고 싶었습니다.

## 어떻게 다른가 (LLM 챗봇과의 차이)

1. **축적된 패턴에서 도출** — 일기 한 편으로는 아무것도 안 뜹니다. 세 편이 모여야 별자리가 뜨고, 결과는 "당신의 일기에서 '다시'라는 말이 네 번 나왔어요"처럼 실제 기록을 인용합니다.
2. **사용자가 고른다** — 기록이 가리킨 후보 두 개 중 하나를 사용자가 선택합니다. 검사가 나를 규정하는 게 아니라, 내가 내 이야기를 고릅니다.
3. **기록이 남고 비교된다** — 별자리는 한 번 뜨면 바뀌지 않고, 이야기는 장(章)으로 쌓입니다.
4. **행동 → 추적 → 회고** — 신화의 교훈을 철학 개념으로 재해석해 "이번 주 이렇게 해보는 건 어떨까요" 하나로 끝나고, 다음 일기에서 그 실천이 읽히면 별이 밝아집니다.

## 흐름

```
일기 작성 ─▶ Gemini가 Big5(OCEAN) 신호로 채점 ─▶ 별 하나
                                                  │ 3편 누적
                                                  ▼
                              10개 페르소나 프로필과 거리 계산 ─▶ 후보 2개
                                                  │ 사용자 선택
                                                  ▼
                           별자리 확정 (핵심 3편 고정) ─▶ 이야기 생성
                                                  │
              ① 기록에서 반복된 것 ② 신화 (일기 장면을 나란히) ③ 철학의 재해석 ④ 이번 주 제안
```

## 설계 원칙

- **고정 세트 + LLM은 개인화만**: 페르소나 10개, 별자리, 철학 개념, 신화 요약은 모두 고정 데이터. LLM은 "왜 이 신화가 지금 당신과 닮았는지"만 씁니다.
- **채점 일관성**: −2~+2 정수 5단계, few-shot 채점표 고정, temperature 0, 완성된 별자리는 재계산하지 않음.
- **환각 방지**: 키워드는 일기에 실제로 있는 표현만 통과, 반복 횟수는 코드가 세어서 프롬프트에 주입, 서사에 인용이 없으면 재생성.
- **진단이 아니라 경향**: "성격이 이렇다"가 아니라 "요즘 기록에 이런 경향이 보인다".

# Few-shot 예시 (2026-09-18 결정권자 확정 톤)

LLM 프롬프트에 고정으로 삽입되는 모범 예시. **톤·분량·구조의 기준**이므로 임의 수정 금지.

| 파일 | 페르소나 | N 방향 | 용도 |
|---|---|---|---|
| `lyra.md` | 3 완주 직전 의심형 (거문고자리) | N↑ (힘든 날) | 채점 예시 + 서사 예시 |
| `perseus.md` | 10 도전 성취형 (페르세우스자리) | N↓ (괜찮은 날) | 채점 예시 + 서사 예시 |

## 각 파일 구조
1. `## 입력` — 일기 3편
2. `## 채점` — 일기별 OCEAN 정수 점수(−2~+2) + N 세부 + 감정 + 키워드 → **채점 프롬프트의 few-shot**
3. `## 매칭` — 1·2·3위와 근거 → 매칭 근거 문장 생성 예시
4. `## 결과 화면` — 사용자에게 보이는 최종 텍스트 → **서사 프롬프트의 few-shot**
   - 반복된 것(일기 직접 인용) → 신화(디테일 위주, 1,000자 내외) → 철학 재해석 → 실행 의도 형식 행동 제안(언제·어디서·무엇을)

## 톤 규칙 (두 예시에서 추출)
- "~하지 마라" 0회. 제안은 항상 "~해보는 건 어떨까요"
- 사용자 일기를 **직접 인용**해 근거 제시 ("Day 3에 ~라고 쓰셨죠")
- 신화의 **디테일**이 개인화의 재료가 됨 (죽은 자의 발은 소리가 없다 → 불안이 만든 문장). 요약 신화 금지
- 표면적 교훈을 먼저 말한 뒤, 철학이 그 교훈의 한계를 짚고 다른 길을 냄
- 욕구·감정을 없애라 하지 않음. 방향·타이밍·순서를 바꾸는 제안
- N↑ 유형: "고쳐보기" 톤 / N↓ 유형: "지키기·돌려주기·넓히기" 톤
- 마지막 줄: 다음 일기에서 실천 언급 시 별이 밝아진다는 안내

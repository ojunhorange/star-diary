# 별자리 조언 전략 시트 — 편집 가이드

여기 있는 `*.md` 10개가 앱의 **원본**입니다. 신화 서술은 Gemini가 자기 지식으로 쓰고, 우리는 **"이 페르소나에게 어떻게 조언할지"** 전략만 정합니다.

고친 뒤 반영: `star-diary` 폴더에서 `npm run content` (배포 시 자동). 형식이 어긋나면 파일·항목을 알려줍니다.

## 형식 (줄 이름은 바꾸지 말 것)

```
# 별자리 이름
페르소나: 이름
한 줄: 페르소나 설명 한 문장 (선택 화면에 보임)
톤: 고쳐보기 / 정리하기 / 넓히기 / 지키기

## 표면적 교훈
신화가 표면적으로 말하는 교훈 한 줄 (철학이 이걸 넘어섬)

## 철학
철학자: 이름
개념: 개념 이름
핵심: 개념을 신화·페르소나와 잇는 한두 문장
비유 힌트: (선택) 비워두면 Gemini가 일기 세계에서 비유를 만듦

## 조언 전략
없애지 말 것: 부정하지 않을 감정·욕구
바꿀 것: A → B (방향·타이밍·순서)
행동의 형태: (선택) 비워두면 Gemini가 "바꿀 것"에서 행동을 설계함
```

## 원칙
- 별자리는 실제 별자리 + 실제 그리스 신화만. 신화가 페르소나를 정직하게 말하지 않으면 끼워 맞추지 않고 뺀다
- 평가 기준: ① 신화 ↔ 표면적 교훈 일치 ② 신화가 페르소나에게 줄 교훈이 있는가 ③ 철학이 신화 주제와 밀접한가
- 파일 이름(id)과 `# 별자리 이름`은 코드의 별 좌표·프로필과 연결돼 있으니 바꾸지 말 것
